# Dispatch
Dispatch is a story-based superhero game developed by AdHoc Studio.
## Story of the Game
The main character is Robert Robertson also known as Mecha Man after losing his suit he starts working as a superhero dispacher and your decisions affect the story
### Main Characters
-Mecha Man
-Invisigal
-Blonde Blazer
### How to Play
1-receive an emergency call
2-check the heroes
3-choose the right hero for the mission
4-wait for the result
